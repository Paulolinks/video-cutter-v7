# Diretório de Referências de Vozes Clonadas

Este diretório armazena arquivos de áudio de referência para vozes clonadas.

## Como usar:

1. Coloque um arquivo de áudio (WAV, MP3) de 10-30 segundos da voz que deseja clonar
2. Renomeie o arquivo para `paulo_links_voice.wav` (ou conforme configurado em vozes_clonadas.json)
3. O sistema usará este arquivo como referência para gerar a voz clonada

## Requisitos do arquivo de referência:

- Duração: 10-30 segundos de áudio limpo
- Formato: WAV preferível, MP3 aceitável
- Qualidade: Sem ruído de fundo, voz clara
- Conteúdo: Fala natural, sem música de fundo
