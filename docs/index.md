# 📚 Documentação - Video Cutter V8

Bem-vindo à documentação completa do Video Cutter V8!

## 🚀 Início Rápido

### Instalação
```bash
git clone https://github.com/seu-usuario/video-cutter-v8.git
cd video-cutter-v8
pip install -r requirements.txt
python app.py
```

### Primeiro Uso
1. Acesse `http://localhost:5000`
2. Configure a IA em "🤖 Configurar IA"
3. Faça upload de um vídeo
4. Execute o corte automático
